# Privacy details

Sourced from `docs/PRIVACY_POLICY.md` and `Spendra/Resources/PrivacyInfo.xcprivacy` in the Spendra repo.

- **Does the app collect any data at all?** Yes — but only user-entered financial records the user chooses to store, synced privately through the user's own iCloud account. No developer-operated analytics or advertising services are included in this release, and no tracking (per the app's privacy manifest, `NSPrivacyTracking` is false with no tracking domains).
- **Information collected** (e.g. account email, device ID, crash logs, analytics events, user-generated content, location): User-generated financial records — expenses, categories, accounts, budgets, recurring items, templates, tags and notes. Optional, user-initiated features may access a selected photo-library image or camera input (on-device receipt scanning via Apple Vision), Face ID/device authentication, notification content for reminders, Siri/App Intents input, and Apple Watch expense entries transferred through WatchConnectivity. Export creates CSV files or versioned JSON backup files only where the user chooses to save or share them.
- **Why each item is collected:** Financial records are the app's core purpose (expense tracking and budgeting). Camera access is only for taking a receipt photo when the user chooses it; existing images can be selected without camera access. Receipt text recognition runs on-device. Face ID protects app access if the user enables it. Notifications deliver reminders the user configures. Siri/App Intents and Apple Watch receive or transfer only the details needed to perform the expense action the user requested. Export and restore exist so the user can retain, move or recover their own records.
- **Third-party services used** (e.g. Firebase, RevenueCat, Sentry, ad networks) and what they receive: None. Spendra syncs through Apple's private CloudKit container and does not integrate third-party analytics, crash reporting, or ad networks. Apple Watch entries transfer to the paired iPhone via WatchConnectivity before syncing. Apple may process purchase/App Store/device-service information under its own terms for optional in-app purchases; Spendra does not receive full payment details.
- **Data retention & deletion:** Records are stored in the user's private iCloud database and stay under the user's control. The user can delete individual records or use Settings to reset all records, which propagates deletion across synced devices. Restoring a versioned JSON backup replaces synced app records after confirmation. Preferences/settings remain device-local. Uninstalling the app may also remove its locally stored data, subject to iOS/macOS backup and restore behavior.
- **Directed at children?** No — Spendra is a general-audience personal finance utility and is not directed to children.
- **Account required to use the app?** No — no sign-in or account creation is required; sync relies on the user's existing iCloud account.
