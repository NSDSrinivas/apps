# Product-page screenshots

Updated October 15, 2026 for Number Spark 1.5. The product page uses unmodified
native simulator captures, grouped by iPhone, iPad, and iPhone Duo. The hub uses
the same iPhone Home and gameplay captures. The app icon is unchanged and matches
`iOS/NumberCircuit/Assets.xcassets/AppIcon.appiconset/AppIcon1024x1024.png`.

## Sources

Paths below are relative to the NumberCruncher repository. The adjacent source
`capture-manifest.jsonl` files record the simulator, source/binary hashes, theme,
and capture settings. `sources.json` records each web copy's source and SHA-256.

- iPhone Home, gameplay, Results, and Streak: October 14 captures from
  `Marketing/Video/2026-10-14-cinema-v2/Captures/`, version 1.5 (2).
- iPhone Pleasant and Minimal Home, and all three iPad Home themes:
  `iOS/AppStore/1.5/draft 2/raw/`, version 1.5 (0), October 13.
- iPad gameplay, Results, and Streak:
  `iOS/AppStore/1.5/draft 1/raw/iPad/vibrant-final/`.
- Duo closed Home (three themes), open gameplay/Results/Streak, and partially
  folded Home: `iOS/AppStore/1.5/draft 2/raw/Duo/`, version 1.5 (0), October 13.

All captures use dark appearance, default text size, deterministic fixture data,
and settled decorative motion. Pro is enabled for capture; Pleasant and Minimal
require the optional Pro purchase. Sample scores and history are fixtures.
No generated device artwork or AI-created product pixels are used in the gallery.

## Order and preserved assets

The iPhone and iPad galleries show Home, gameplay, Results, Streak, Pleasant,
and Minimal. The Duo gallery shows closed Home in all three themes, open
landscape gameplay and Results, partially folded Home, and open portrait Streak.
Native aspect ratios are preserved by the shared gallery styles and device tabs.

The existing `iphone/app-store/`, `ipad/app-store/`, and root-level marketing
images are retained as historical assets and are no longer referenced by the
product page. Their older generation provenance is not evidence for these new
native captures.
